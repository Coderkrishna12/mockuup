# Character Mask PNGs

Place character face/helmet mask overlay PNGs here.
These are overlaid on the user's face in the AR experience.

## Required Files (transparent PNG, ~500-800px wide):

| Filename | Character | Description |
|----------|-----------|-------------|
| `iron-man.png` | Iron Man | Helmet/faceplate |
| `spider-man.png` | Spider-Man | Full face mask |
| `captain-america.png` | Captain America | Helmet with A |
| `thor.png` | Thor | Winged helmet |
| `hulk.png` | Hulk | Green face/rage |
| `black-panther.png` | Black Panther | Vibranium mask |
| `doctor-strange.png` | Doctor Strange | Eye of Agamotto necklace |
| `ant-man.png` | Ant-Man | Helmet |
| `war-machine.png` | War Machine | Helmet |
| `thanos.png` | Thanos | Helmet |

## Where to find these images:
- Search Google for "[character name] mask PNG transparent"
- Or "[character name] helmet PNG"
- Must be transparent background, face/head-only
